Four Steps to SSO

Integrate "Sign in with S-Auth" into your app in under 10 minutes.

1

Register Your App

Get a client_id and secret from the admin dashboard.

2

Redirect to S-Auth

Send users to /oauth/authorize with your client_id.

3

User Authenticates

S-Auth handles login, consent, and redirects back with a code.

4

Exchange for Token

POST to /oauth/token to get a JWT with user info.

login-button.jsx 
function SignInWithSAuth() {
  const handleLogin = () => {
    const params = new URLSearchParams({
      client_id: 'sauth_a1b2c3...',
      redirect_uri: 'http://localhost:3000/callback',
      response_type: 'code',
      scope: 'profile email'
    });
    window.location.href =
      `https://auth.susindran.in/oauth/authorize?${params}`;
  };

  return (
    <button onClick={handleLogin}>
      🔐 Sign in with S-Auth
    </button>
  );
}
